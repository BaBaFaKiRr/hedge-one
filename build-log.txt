🧠 Root Cause (Confirmed from your code)

From :

return (
  <div
    id={containerId}
    className="h-full min-h-[400px] w-full overflow-hidden rounded-lg border ..."

👉 This is the problem.

Why?
TradingView injects an iframe inside this div
If parent height is unstable → h-full fails
min-h-[400px] forces weird partial layout (chart never truly fills)
